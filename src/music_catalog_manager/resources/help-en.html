1. Getting started and folders

  1. Click Add folder and select your main music folder. Subfolders are scanned too. Audio stays on disk; scanning does not modify it.
  2. Wait for the report. Cancel stops between files; completed catalog entries remain.
  3. Rescan reads new and changed files. A disconnected drive marks entries unavailable instead of deleting them.
  4. Folders lists locations, availability and the last scan. After moving a whole folder, select New location and rescan.

Readable formats: MP3, FLAC, audio M4A/MP4, OGG, OPUS, WAV, WMA and AIFF. WMA is read/playback only.

2. Library, filters and grouping

Search tags and paths. Results load in the background, 250 entries per page; navigation below the table changes pages. Click a column header to sort. Use Ctrl/Shift to select multiple rows.

Advanced filters expands artist, album, genre, date, format, folder and grouping. Quick filters show missing tags, missing artwork, pending changes or unavailable files. Clear filters removes all restrictions.

Choose Group by → Playlist, then select a saved list in the second selector. Entries appear in playlist order, including repeated tracks. Clicking a header changes the order; select the playlist again to restore it. “All” shows the entire library.

Albums shows a cover grid; double-click an album to open it. The Columns menu controls visible fields. Window layout, column widths and sorting are remembered. Compact windows move some buttons into Tools; use Track details for the detail dialog.

3. Playlists and importing folders

Select tracks and choose Tools → Save selection as playlist. The Playlists view supports playback, showing entries, drag-and-drop reordering, removing entries and M3U/M3U8 export. Deleting a playlist does not delete music files.

Import playlist opens one file. Supported import formats are M3U, M3U8, PLS, WPL and XSPF. Relative paths are resolved against the playlist's folder. Internet stream URLs are not added to the local catalog.

  1. Choose Tools → Import playlists from folder, or the matching button in Playlists.
  2. Select the main folder. The app discovers lists in it and all subfolders, skipping symbolic links and junction points.
  3. Select the lists to import. Catalog audio in this folder and subfolders before importing is enabled by default, so new audio in that area can be matched.
  4. Files outside the chosen folder must already exist in the app catalog. The report lists matched entries, unmatched paths and errors for each playlist.
  5. Reimporting the same source path updates its previously imported list. Unrelated lists with the same name get distinct names. Order and repeated entries are preserved.

Cancellation keeps completed imports. Playlist files are limited to 8 MiB. Legacy M3U/PLS files fall back to the Windows system encoding when they are not UTF-8 or UTF-16.

4. Playback and queue

Double-click or Enter starts a track. Space in the table toggles play/pause. A single selection builds a queue from every result of the current filter, across all pages; multiple selections queue only those entries. Changing filters does not alter an existing queue.

Controls include previous/next, pause, stop, seeking, volume, Shuffle, repeat track and repeat queue. Queue lets you reorder or remove entries. Before file edits the app releases the playing file.

5. Online and local cover artwork

Select the track or tracks that should receive artwork. Commands are available in the detail panel, Tools menu and table context menu.

  1. Find cover online prefills album artist (falling back to track artist) and album title from tags. Correct either field, then click Search online.
  2. The app searches MusicBrainz releases and fetches previews from Cover Art Archive. It shows up to 8 distinct covers with release details. No MBID is required. For this feature the default contact header uses the project's website; a contact configured in Settings takes precedence.
  3. Select a result and preview its destination before saving. If nothing is found, try another spelling or choose an image from disk. Network errors are shown separately from absent results.
  4. Choose local image accepts JPEG and PNG, up to 20 MiB and 25 million pixels. It works offline and normalizes images to JPEG.

Search sends artist and album, not audio or the whole library. Verify suggestions before applying them. Artwork is not available for every album or edition. Direct MBID lookup remains an advanced option under Artwork.

6. Tags and metadata

Edit tags changes checked fields only. A checked blank value removes that field. The default destination is the catalog; writing audio is a separate option. Preview shows the scope. Write pending tags writes the complete catalog tag set to selected audio files and creates original backups.

Album metadata lets you choose a MusicBrainz edition and match tracks by disc/track numbers or an unambiguous title. Changes go to the catalog first. Configure a real contact in Settings for metadata integration. Tags from filename accepts templates such as {tracknumber} - {artist} - {title}. All selected names must match; changes are previewed.

Rename accepts templates such as {track:02} - {title}, preserves folders and extensions and checks collisions before moving files.

7. Undo and backups

Undo database edit undoes the entire last batch edit, including after restarting. It does not restore audio. Restore original audio uses the backup registry, checks SHA-256, saves a safety copy of the current file and restores catalog tags and artwork too. Older unregistered copies require manual restoration.

Backups creates/restores ZIP archives containing the database and cached artwork. Catalog ZIP backups do not contain music or original-audio backups. Make a separate full music backup on another drive. Restoring a catalog creates a safety backup and previews replacement of the library.

Version 0.4.0 uses database schema 2, as does 0.3.0. Schema 1 profiles are migrated. Version 0.2.0 cannot open a migrated database.

8. Other tools

Collection quality reports missing tags, covers, numbering gaps and artist spelling variants. Duplicates identifies identical files by SHA-256: enable hashing and rescan first. Editing tags changes the whole-file hash.

Compare recordings provides metadata/duration candidates and a local comparison of the first 60 seconds of 2–20 selected files. Scores are experimental suggestions, not proof of identity; silence and short samples may be insufficient. No duplicate is deleted automatically.

Export writes all matching entries across all pages to CSV/JSON. History lists recent operations and errors. Open location selects a file in Windows Explorer.

9. Settings and shortcuts

Settings include PL/EN language, system/light/dark theme, metadata-service contact and SHA-256. The default profile is %LOCALAPPDATA%\MusicCatalogManager. For a separate profile use MusicCatalogManager.exe --profile C:\TestProfile. Do not open one profile in two instances.

10. Troubleshooting

  • No entries after import: check unmatched paths in the report. Enable cataloging before folder import; add audio outside that folder to the catalog first.
  • No playlists in grouping: save or import a list, then choose Advanced filters → Group by → Playlist.
  • No covers: correct album/artist spelling, check the connection or choose a local JPEG/PNG. Not every release has artwork.
  • Unavailable file: connect the drive or use New location in Folders. Do not delete catalog entries just because media is offline.
  • Decoder error: check file integrity and format. DRM and all codec variations are not supported.
  • Waiting to close: the app requests cancellation and waits for a safe stop. A network request may wait up to its 15-second timeout; some stages finish the current file first.
